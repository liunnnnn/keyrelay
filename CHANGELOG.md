# Changelog

## 0.1.0 - KeyRelay

- Reposition as a macOS keyboard input tool for remote desktop clients and VM consoles.
- Add a shared remote-client adapter registry and GUI selection.
- Add --client and --list-clients, per-client delay defaults and explicit validation status.
- Retain original physical US keys, Shift/Ctrl handling, Tab expansion, Enter permission and cancellation.
- Preserve vmtype CLI compatibility and add the keyrelay entry point.
- Include experimental Sunlogin, ToDesk and UU presets for staged testing, without claiming verified compatibility.
- Add adapter development notes, compatibility evidence and regression checks.

## Legacy baseline

KeyWeaver 1.2.1 provides the preserved input planning fixtures and sender behavior. The legacy native text-field repeated-character limitation remains documented.
